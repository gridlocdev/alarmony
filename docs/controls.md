# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux), and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**). That window is built from the same list as the menus, so it is always up to date.

Single-letter keys only work when you aren't typing in a box.

In a browser tab, the browser keeps **⌘N** (**Ctrl+N**) for its own windows, so use **N** there. The desktop app has both.

## Tabs and windows

|                                      | macOS         | Windows / Linux      |
| ------------------------------------ | ------------- | -------------------- |
| Stopwatch                            | **⌘3**        | **Ctrl+3**           |
| Timers                               | **⌘4**        | **Ctrl+4**           |
| Next / previous tab (in the tab row) | **→** / **←** | **Right** / **Left** |
| Command menu                         | **⌘K**        | **Ctrl+K**           |
| Keyboard Shortcuts                   | **⌘/**        | **Ctrl+/**           |
| Settings                             | **⌘,**        | **Ctrl+,**           |
| Close a window or the command menu   | **⎋**         | **Esc**              |

## Stopwatch

|                       | macOS | Windows / Linux |
| --------------------- | ----- | --------------- |
| Start or stop         | **␣** | **Space**       |
| Lap (while running)   | **L** | **L**           |
| Reset (while stopped) | **R** | **R**           |

## Timers

|                                     | macOS           | Windows / Linux             |
| ----------------------------------- | --------------- | --------------------------- |
| New timer                           | **⌘N** or **N** | **Ctrl+N** or **N**         |
| Start the new timer                 | **↩** or **⌘↩** | **Enter** or **Ctrl+Enter** |
| Pause or resume the selected timer  | **␣**           | **Space**                   |
| Edit the selected timer             | **↩**           | **Enter**                   |
| Delete the selected timer           | **⌫** or **⌦**  | **Backspace** or **Delete** |
| Stop ringing (on the ringing sheet) | **↩** or **⎋**  | **Enter** or **Esc**        |

Click a timer to select it, or move to it with **Tab**. Its card has the same actions as buttons. Cancel, Restart, Save as Preset and Pause All Timers are in the command menu and the menu bar.

## Undo

|      | macOS   | Windows / Linux  |
| ---- | ------- | ---------------- |
| Undo | **⌘Z**  | **Ctrl+Z**       |
| Redo | **⇧⌘Z** | **Ctrl+Shift+Z** |
