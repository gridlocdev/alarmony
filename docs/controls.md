# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux), and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**). That window is built from the same list as the menus, so it is always up to date.

Single-letter keys only work when you aren't typing in a box.

In a browser tab, the browser keeps **⌘N** (**Ctrl+N**) for its own windows, so use **N** there. The desktop app has both.

## Tabs and windows

|                                      | macOS         | Windows / Linux      |
| ------------------------------------ | ------------- | -------------------- |
| World Clock                          | **⌘1**        | **Ctrl+1**           |
| Alarms                               | **⌘2**        | **Ctrl+2**           |
| Stopwatch                            | **⌘3**        | **Ctrl+3**           |
| Timers                               | **⌘4**        | **Ctrl+4**           |
| Next / previous tab (in the tab row) | **→** / **←** | **Right** / **Left** |
| Command menu                         | **⌘K**        | **Ctrl+K**           |
| Keyboard Shortcuts                   | **⌘/**        | **Ctrl+/**           |
| Settings                             | **⌘,**        | **Ctrl+,**           |
| Close a window or the command menu   | **⎋**         | **Esc**              |

## World Clock

|                                          | macOS                   | Windows / Linux                    |
| ---------------------------------------- | ----------------------- | ---------------------------------- |
| Add a clock (on the World Clock tab)     | **⌘N** or **N**         | **Ctrl+N** or **N**                |
| Add the highlighted place (in Add Clock) | **↩**                   | **Enter**                          |
| Move between clocks                      | **←** **→** **↑** **↓** | **Left** **Right** **Up** **Down** |
| Rename the selected clock                | **↩**                   | **Enter**                          |
| Move the selected clock up / down        | **⌥↑** / **⌥↓**         | **Alt+Up** / **Alt+Down**          |
| Delete the selected clock                | **⌫** or **⌦**          | **Backspace** or **Delete**        |
| Cards or list                            | **⌘L**                  | **Ctrl+L**                         |

Add Clock stays open after each place, so you can add several; press **⎋** when done.

## Alarms

|                                               | macOS           | Windows / Linux             |
| --------------------------------------------- | --------------- | --------------------------- |
| New alarm (on the Alarms tab)                 | **⌘N** or **N** | **Ctrl+N** or **N**         |
| Save the new alarm                            | **↩**           | **Enter**                   |
| Hour or minute up or down (in the time field) | **↑** / **↓**   | **Up** / **Down**           |
| Move between alarms                           | **↓** / **↑**   | **Down** / **Up**           |
| Turn the selected alarm on or off             | **␣**           | **Space**                   |
| Edit the selected alarm                       | **↩**           | **Enter**                   |
| Delete the selected alarm                     | **⌫** or **⌦**  | **Backspace** or **Delete** |
| Snooze (on the ringing sheet)                 | **S**           | **S**                       |

An existing alarm's editor saves each change as you make it. Duplicate Alarm is in the command menu and the menu bar. Snooze rings the alarm again after the snooze length in Settings, on this device only.

## Stopwatch

|                       | macOS | Windows / Linux |
| --------------------- | ----- | --------------- |
| Start or stop         | **␣** | **Space**       |
| Lap (while running)   | **L** | **L**           |
| Reset (while stopped) | **R** | **R**           |

## Timers

|                                     | macOS           | Windows / Linux             |
| ----------------------------------- | --------------- | --------------------------- |
| New timer (on the other tabs)       | **⌘N** or **N** | **Ctrl+N** or **N**         |
| Start the new timer                 | **↩** or **⌘↩** | **Enter** or **Ctrl+Enter** |
| Pause or resume the selected timer  | **␣**           | **Space**                   |
| Edit the selected timer             | **↩**           | **Enter**                   |
| Delete the selected timer           | **⌫** or **⌦**  | **Backspace** or **Delete** |
| Stop ringing (on the ringing sheet) | **↩** or **⎋**  | **Enter** or **Esc**        |

Click a timer to select it, or move to it with **Tab**. Its card has the same actions as buttons. Cancel, Restart, Save as Preset and Pause All Timers are in the command menu and the menu bar.

| Redo | **⇧⌘Z** | **Ctrl+Shift+Z** |
